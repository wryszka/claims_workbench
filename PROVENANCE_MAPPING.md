## What we extended / added

| Extension | Why it advances the asset |
|---|---|
| **Guidewire ClaimCenter CDA-style ingestion** | Makes intake legible to real Guidewire shops; positions Databricks as system of intelligence downstream of the system of record |
| **Agent Bricks multi-agent supervisor ("Claims AI")** + 5 specialist agents (360, Challenge, Fraud, Recovery, Audit) | Moves from a single scoring model to a governed, multi-agent reasoning system with a second opinion |
| **Auto-close straight-through workflow + configurable risk-appetite threshold** | Turns "routine vs investigate" routing into auto-close-and-pay with an explainable, configurable band |
| **Reserving bracket model + reserve-adequacy story** | Adds an actuarial dimension the accelerator doesn't have |
| **Agent-reasoning audit log (regulator-viewable) + "what's collected" governance** | Makes governance the headline — lineage, sensitivity tiers (incl. Secret/CMK), full reasoning trail |
| **Persona surfaces — control tower, handler "My Queue", create-a-claim** | Serves leadership, handler, and intake personas, not just a data-science notebook |
| **Personal-lines scenario (motor + home), Bricksurance SE** | Aligns with the EMEA personal-lines audience; consistent with the pricing & Solvency 2 demos |
